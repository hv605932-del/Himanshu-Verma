# AKTU Study Hub

A modern, responsive EdTech web app concept for AKTU students. It supports B.Tech, MBA, Polytechnic, BCA, MCA, and other AKTU courses with study materials organized course-wise, semester-wise, subject-wise, and unit-wise.

## Features

- Hero banner with primary learning and notes actions
- Course, semester, subject, and unit-wise study material explorer
- Notes PDF, videos, PPTs, assignments, and important questions structure
- Previous year question paper filtering and download CTAs
- Online class area with embedded-player style UI, playlist, and continue watching state
- Student dashboard for login/signup, bookmarks, downloads, search, and recently viewed content
- Admin dashboard for adding courses, semesters, subjects, units, uploads, edits, deletes, user management, and analytics
- Dark/light mode, animated transitions, and mobile-friendly navigation
- Express API scaffold for catalog and admin uploads

## Tech Stack

- React + Vite
- Tailwind CSS
- Framer Motion
- Node.js + Express
- Multer for upload endpoint scaffolding

## Getting Started

```bash
npm install
npm run dev
```

Run the API server separately:

```bash
npm run server
```

Or run both together:

```bash
npm start
```

## Build

```bash
npm run build
```
